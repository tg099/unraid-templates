# Unraid templates

Docker templates for [Unraid](https://unraid.net) Community Applications.

| App | Template | Docs |
|---|---|---|
| [Crossfade](https://github.com/tg099/crossfade) | [templates/crossfade.xml](templates/crossfade.xml) | [Crossfade on Unraid](https://github.com/tg099/crossfade/blob/main/docs/unraid.md) |

## Install

**Apps** tab → search for the app → **Install**.

Not listed yet, or want to try a template change first? *Settings → Docker* (Advanced View) → *Template
repositories* → add `https://github.com/tg099/unraid-templates` → *Apply*. Then *Docker → Add Container* and pick
the template.

## Support

- Problems with the app: the app's own issues, e.g. [Crossfade issues](https://github.com/tg099/crossfade/issues).
- Problems with a template (wrong default, missing setting): [issues here](https://github.com/tg099/unraid-templates/issues).
